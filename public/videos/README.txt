PHYSIO CATEGORIES — service videos
==================================

Drop one short (a few seconds), muted-friendly MP4 per service into THIS folder,
using these exact file names. Each plays as a small looping clip on its card.

  orthopedic.mp4               -> Orthopedic Physiotherapy
  sports-injury.mp4            -> Sports Injury Rehabilitation
  neurological.mp4             -> Neurological Physiotherapy
  spine-care.mp4               -> Spine Care & Manual Therapy
  post-surgical.mp4            -> Post-Surgical Rehabilitation
  ankylosing-spondylitis.mp4   -> Ankylosing Spondylitis
  geriatric.mp4                -> Geriatric Physiotherapy
  home-physiotherapy.mp4       -> Home Physiotherapy Services

Notes
-----
- Format: H.264 MP4, ~720p or smaller, a few seconds, no audio needed.
- Until a file is added, the card shows its (already relevant) poster image,
  so the section never looks broken.
- To change a file name or path, edit the `video:` value in
  src/components/Services/Services.jsx

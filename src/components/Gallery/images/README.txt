DROP YOUR GALLERY IMAGES HERE
=============================

Save the Addlife Physiocare images (the flyers, clinic photos, posters, etc.)
into THIS folder. Any file ending in .jpg .jpeg .png .webp or .avif is picked
up automatically and shown in the horizontal scrolling gallery on the home
page — you do NOT need to edit any code.

Tips:
- They display in alphabetical / numeric order, so name them like
  01.jpg, 02.jpg, 03.jpg ... to control the order.
- All images are shown at the same height (360px) with their natural width,
  so both square flyers and wide clinic banners look fine.
- The strip auto-scrolls and pauses when you hover over it.

After adding files, the dev server (npm run dev) hot-reloads automatically.
